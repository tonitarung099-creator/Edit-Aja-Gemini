# Examples

Standalone example inputs are grouped here by feature domain.

| Directory | Purpose |
| --- | --- |
| `caption/` | Speaker/style configuration examples. |
| `creator/` | Creator Pipeline examples. |
| `dialogue/` | Dialogue review/approval examples. |
| `documentary/` | Documentary graphics, B-roll, motion graphics and montage examples. |
| `segmentation/` | Segmentation prompt examples. |

The AI Edit JSON specification keeps its own examples under
`ai-edit/examples/` because those files are part of that format specification.

Feature documentation is under `docs/features/`.
